# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues. Use GitHub's private vulnerability reporting/security advisory flow when it is enabled for the repository.

When reporting, include the affected component, impact, reproduction steps, and any suggested mitigation.

## Development security gates

The repository uses dependency review, npm audit, typed security/audit boundaries, and CI certification checks. Security-sensitive changes should remain isolated from unrelated refactors.

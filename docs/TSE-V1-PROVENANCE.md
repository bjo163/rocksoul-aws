# TSE V1 Provenance

Every temporal state records:

- provider id and version;
- algorithm version and provider confidence metadata;
- canonical UTC convention;
- horizon/refraction and rise/set convention;
- search-window size and provider capabilities;
- IANA timezone and night definition;
- data quality and resolved/unresolved status.

Astronomical provenance does not become Qur'anic evidence. Qur'anic evidence
must retain its corpus/parser revision and evidence class; research
interpretation remains E5 and cannot be promoted to explicit revelation.

# ADR-0001 — MoonWitness Civic Command UI

Status: **Superseded for Cosmic repository scope**  
Original date: **2026-08-22**

This ADR records an earlier full-product architecture in which Web, XRP, CAB, Flow, and a shared UI package lived in Cosmic.

Cosmic is now engine/API-first. Product UI architecture, visual language, accessibility/localization, browser navigation, and hosting belong to the repositories that own those applications. This ADR remains only as historical design context and is not a Cosmic release or implementation contract.

Current Cosmic scope is defined by [`README.md`](README.md), [`ARCHITECTURE.md`](ARCHITECTURE.md), and [`PACKAGE_ARCHITECTURE.md`](PACKAGE_ARCHITECTURE.md).
